# Obsidian RAG 0.2.0

这是“个人知识工作台”的首个可安装试用版本。

## 已包含

- Windows x64 当前用户安装，无需 Python、Node.js 或 Docker；
- 连接多个 Markdown 文件夹，上传 Markdown/文字型 PDF；
- 后台导入、版本快照、关键词搜索、章节/行号/页码来源阅读；
- Ollama 与 DeepSeek 流式问答、停止、重试、会话恢复和简单追问；
- 收藏、备注、来源回看、四类本地反馈和 Markdown 导出；
- 数据备份/校验恢复、迁移失败安全模式和脱敏诊断。

## 已知限制

- 产品问答当前仍以 BM25 检索为主，E5 产品向量索引尚未接入；
- 扫描 PDF 没有 OCR，复杂表格和图表不能可靠重建；
- 追问只覆盖常见代词和省略问法；
- 无账号、云同步、联网搜索、自动更新或遥测；
- 回答显示的有效引用表示标签能对应来源，不保证结论必然正确。

## 试用状态

开发机上的合成资料、真实浏览器、本机 Ollama、发布包和安装/卸载流程已经验收。至少两位朋友的独立电脑试用仍为**待试用**，不计为已完成。
