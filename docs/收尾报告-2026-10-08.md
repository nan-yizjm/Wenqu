# Wenqu 0.2.3 收尾报告

本次范围是安全修复、测试、文档、打包发布与冗余清理，不新增产品功能。仓库继续保持私有，用户数据目录与正式安装 AppId 保持兼容。

## 修复与证据

| 问题 | 处理与回归覆盖 |
| --- | --- |
| Ollama 地址前缀校验可被伪装域名和用户信息段绕过 | 按 URL 解析协议、主机、端口与路径，拒绝非法配置并返回 422；覆盖 `localhost.evil`、`127.0.0.1@evil`、无效端口、协议与空白字符 |
| 本机不同端口或伪造 Origin 可绕过来源检查 | Origin 与请求协议、主机和端口精确匹配，非法来源返回 403；无 Origin 的本机 API 调用仍兼容 |
| ZIP 恢复在 Windows 下可能越界或覆盖规范化后的同名文件 | 拒绝反斜杠、盘符、穿越、保留设备名、非法字符、符号链接、大小写重名；写入前再确认恢复目录边界 |
| 损坏清单或数据库产生 500 | 校验清单对象、版本、文件元数据、长度及 SHA-256；损坏 ZIP、清单与 SQLite 统一拒绝，测试确认原数据库与资料不变 |
| 自动渲染首先选择的 Edge 失败后不尝试 Chrome | 自动候选依次尝试，为后续浏览器保留超时预算；显式指定时保持该选择；失败记录原因，临时文件和进程清理后才降级到 HTML |
| 构建可能忽略外部命令的失败 | npm、pip、许可清单、PyInstaller、Inno Setup 的失败立即终止构建 |
| 临时安装验收可能触碰正式安装 | 验收重新编译专用 AppId，隔离安装目录与数据目录；升级仅删除本次 `{app}` 的旧入口，不递归删除固定旧品牌目录 |
