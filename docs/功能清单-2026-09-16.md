# 功能清单

> 2026-09-16 ｜ 按模块列，只列功能本身

---

## 一、Studio 式产出（从检索结果一键生成）

| # | 功能 | 说明 |
|---|---|---|
| 1 | 学习指南 | 基于检命中的片段生成结构化要点 |
| 2 | FAQ | 自动生成高频问答对 |
| 3 | 简报文档 | 执行摘要式输出 |
| 4 | 思维导图 | 输出 Mermaid mindmap / markmap，落进 vault 可渲染 |
| 5 | 时间线 | 按时间整理事件 |
| 6 | 测验题 | 选择题 / 简答，带答案与出处 |
| 7 | 闪卡 | 问答对 / Cloze 填空，导出为 markdown 卡片 |
| 8 | PPTX | 生成可编辑幻灯片 |
| 9 | 信息图 | LLM 出 HTML/SVG → 渲染成 PNG |
| 10 | 产物落盘 | 所有产出写成 vault 里的 `.md` |
| 11 | 要点回链 | 每条要点带块引用 `^block-id` 指回原文 |
| 12 | 产出面板 | 生成前预览、可改格式、可重生成 |

---

## 二、记忆系统

| # | 功能 | 说明 |
|---|---|---|
| 13 | 会话记忆 | 多轮追问的上下文保持 |
| 14 | 偏好记忆 | 记住输出语言 / 详略 / 格式偏好 |
| 15 | 项目记忆 | 记住当前主题与关注的笔记集 |
| 16 | 事实抽取 | 从对话与笔记抽实体和断言（进阶） |
| 17 | 冲突消解 | 同一事实出现多个版本时判定谁有效 |
| 18 | 时效判定 | 事实带有效期，旧版本自动失效 |
| 19 | 记忆面板 | 可查看全部已存记忆 |
| 20 | 记忆管理 | 编辑 / 删除 / 一键清空 |
| 21 | 记忆来源 | 每条记忆标明来自哪次对话、哪篇笔记 |
| 22 | 记忆开关 | 默认关，用户显式开启 |

---

## 三、联网补充（MCP / API）

| # | 功能 | 说明 |
|---|---|---|
| 23 | 联网开关 | 默认关，用户主动开启 |
| 24 | 搜索接入 | 接 Tavily / Brave / SearXNG 等搜索 API |
| 25 | MCP 客户端 | 接外部 MCP server 当作工具调用 |
| 26 | 来源分层 | 回答中区分"来自你的笔记"与"来自网络" |
| 27 | 网络引用 | 网络来源带链接与抓取时间 |
| 28 | 冲突提示 | 库内与网络说法矛盾时显式提示 |
| 29 | 时效标注 | 网络内容新于笔记时标注出来 |
| 30 | 自动降级 | 断网 / 失败时静默退回纯库内检索 |

## 四、多模态

| # | 功能 | 说明 |
|---|---|---|

## 五、Demo 与基础支撑

| # | 功能 | 说明 |
|---|---|---|
| 35 | 受限在线 Demo | 预置示例语料，访客只读，不可上传 |
| 36 | 浏览器内本地检索 | WASM / WebGPU 在浏览器里做检索，语料不上传 |
| 37 | 统一落盘 | 所有产出走 vault 原子落盘（`.tmp` + `replace`） |
| 38 | 评测扩展 | 每个新模块配一组可跑出数字的评测 |
| 39 | 库内 Deep Research | 多跳检索 → 综合成一篇带双链的研究笔记 |

## 六、明确不做的

| 功能 | 原因 |
|---|---|
| 通用代码执行 | 沙箱安全责任重，个人知识库用不上 |
| 视频生成 | 重资产，收益不成比例 |
| 自动整理全库（批量改文件） | 风险高，且 Claudian 已占位 |
| 团队协作 / 权限 | 不是个人产品的战场 |
