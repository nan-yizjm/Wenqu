# 实验环境重建

产品环境统一为 Python 3.12 + CPU PyTorch 的 `.venv-product`，安装与测试步骤见根 README。原本机 Python 3.14 CUDA 环境在 0.2.3 收尾后移除；实验源码、题集、学习记录、训练权重和私人运行资料保留。

## CPU 学习实验

BM25、Attention、小型 Decoder 与本仓库离线测试可以使用产品 CPU 环境。小型训练的配置文件 `tiny_lm.toml` 默认写了 `device = 'cuda'`，在自己的配置副本里改为 `cpu` 后再运行，勿直接照搬历史硬件设置。

```powershell
.\.venv-product\Scripts\python.exe -X utf8 -m src.attention_lab --help
.\.venv-product\Scripts\python.exe -X utf8 -m src.train_tiny_lm --help
```

## CUDA / QLoRA

CUDA 训练使用单独环境，避免替换产品 CPU PyTorch：

```powershell
py -3.12 -m venv .venv-experiments
# 根据本机驱动与官方 PyTorch 安装说明选择 CUDA wheel，然后安装：
.\.venv-experiments\Scripts\python.exe -m pip install -r requirements-training.txt -r requirements-vector.txt
.\.venv-experiments\Scripts\python.exe -X utf8 -m src.train_qlora --help
```

PyTorch CUDA wheel 必须由实验者根据驱动和 GPU 选择，不把历史开发机 CUDA 配置视为通用要求。训练依赖是历史复现基线，运行前也应审计；产品环境的依赖审计不覆盖另建的实验环境。

`qlora.toml` 固定了基础模型 revision，`data/` 顶层保存已跟踪题集；私人语料、adapter 与 checkpoint 在被忽略的生成目录中，不随 Git 克隆。复现的是方法和判据；缺少原私人语料时无法保证复现原始数字。
