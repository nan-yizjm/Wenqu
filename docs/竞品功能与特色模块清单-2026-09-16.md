## 一、商业产品

### 1. 笔记软件自带 AI

#### Notion AI
**定位**：把整个工作区变成可对话的知识库。

- **核心功能模块**
  - 跨页语义搜索（不靠标题，理解上下文定位）
  - AI Q&A：对 workspace 内所有页面提问
  - 关系型数据库：多属性 + Relations/Rollups 查询
  - AI 写作：总结 / 续写 / 润色 / 翻译 / 改语气
  - 会议纪要、模板生成、多语言
  - 权限、评论、实时协同、版本历史
- **特色模块**
  - **All-in-One**：笔记 + 文档 + 数据库 + 项目 + AI 全在一个盒子里
  - **AI Q&A 跨页检索**：把散落页面当知识库问答
  - 1M+ 自定义 Agent、Notion Agent
- **短板**：纯云、来源锚定弱、API 限 3 次/秒、块结构对 LLM 取数不友好

#### Obsidian（官方 + 社区）
**定位**：本地 Markdown 笔记软件，**官方刻意不做 AI**。

- **核心功能模块**
  - 本地 Markdown 纯文本存储（零锁定）
  - 双向链接、知识图谱、Canvas 白板
  - Dataview 查询、模板、2000+ 社区插件
  - 官方 Sync / Publish（付费）
- **特色模块**
  - **插件生态本身就是特色**：AI 能力全部由社区承担
  - 迁移成本 <5%（Markdown 纯文本）
  - 5 万篇量级仍能扛（搜索性能）
- **短板**：AI 碎片化（要自己挑插件）、单人为主、协作弱

#### 同赛道其他
| 产品 | 核心功能模块 | 特色模块 |
|---|---|---|
| **Logseq** | 大纲块、双链、图谱 | 块级引用 + 大纲思维 |
| **Roam Research** | 每日笔记、双链、图谱 | 图谱鼻祖，深度写作 |
| **Craft** | 富文档、块编辑、AI 助手 | 视觉精美的文档体验 |
| **Evernote** | 笔记、剪藏、搜索 | 老牌剪藏 + OCR |

### 2. 通用 AI 挂知识库

#### NotebookLM（Google）
**定位**：只吃你上传的资料、严格锚定的研究助理。

- **核心功能模块**
  - 来源锚定问答（RAG）+ **逐段内联引用**
  - 多源导入：PDF / Google Docs·Sheets·Slides / URL / YouTube / 音频 / 图片（单源上限 50 万词）
  - 多 Notebook 并行、共享与协作
  - 1M token 上下文窗口
- **特色模块**
  - **Audio Overview**：把资料变成两位 AI 主持人的播客（无直接竞品）
  - **Video Overview / Cinematic mode**：生成旁白视频，无水印
  - **Studio 面板一键产出**：学习指南 / FAQ / 时间线 / **思维导图** / 幻灯片（可导 PPTX）/ 信息图 / 测验 / 闪卡 / 简报文档
  - **Deep Research**：跨整个 Notebook（最多 50–300 源）出结构化带引用报告
  - **代码执行**：清洗 CSV、出汇总表
- **短板**：**无开放 API、无 MCP**；会话内不联网；数据在 Google 云；国内需代理；HIPAA 仅企业版

#### 腾讯 ima（ima.copilot）
**定位**：国内以知识库为核心的 AI 工作台，微信生态唯一打通。

- **核心功能模块**
  - 个人 / 共享知识库、知识库广场（20+ 领域）
  - 19+ 格式导入（PDF/Word/PPT/Excel/图片…）
  - AI 优先从知识库检索再回答，**回答带原文溯源**
  - 智能总结、思维导图、翻译；写作（教案/周报/PPT 大纲）
  - 四级权限、版本追溯
- **特色模块**
  - **微信生态打通**：公众号文章 / 聊天文件 / 小程序一键原生入库
  - **四层记忆系统**：Soul / User / Memory / Agent（越用越懂你）
  - **技能生态**：自然语言创建自定义 Skills
  - **copilot**：一句话生成报告（20–40 分钟）/ 播客（3–10 分钟）/ PPT
  - **录音转写**：中英文 + 7 种方言；OCR 认手写批注
  - 全端覆盖：Mac/Win/iOS/Android/鸿蒙/小程序/网页/浏览器插件
- **短板**：免费空间偏小；权限/审计弱；模型绑混元有锁定风险；必须联网
- **口径提醒**："国内赛道第一 / 1300万 MAU"为**厂商口径，未独立核实**

#### 飞书知识问答
**定位**：企业内权限感知的 AI 问答中枢。

- **核心功能模块**
  - 20+ 文件格式解析、多轮追问
  - 部门 / 项目专属知识空间，绑定原生权限
  - 实时联网搜索
- **特色模块**
  - **权限感知 RAG**：同一问题，不同权限的人得到不同答案
  - **多阶段重排序**：混合检索 + 权限过滤的工程实现较深
- **短板**：强绑飞书生态；非飞书用户单独引入收益有限；文档量大了搜索下滑

#### 语雀 / Get 笔记
| 产品 | 核心功能模块 | 特色模块 |
|---|---|---|
| **语雀** | 知识库–目录–文档三层结构、自研 Lake 格式、差异快照 | **MCP 开放 19 个标准化工具**给外部 AI 调用；中文写作体验扎实 |
| **Get 笔记** | 语音/图片/链接/文本四输入、AI 摘要 | 得到系生态；手机内录转写；基础功能全免费 |

### 3. 专门的"第二大脑"

#### Mem
**定位**：AI 原生、零组织的自组织工作区。

- **核心功能模块**
  - 一处快捷捕获（键盘快捷键 + 自动保存）
  - AI 自动打标、建立关联、分组
  - **Mem Chat**：跨全库自然语言问答
  - 每日回顾推送
- **特色模块**
  - **零组织**：你不用建文件夹、不用打标签
  - 语义检索精度高（第三方 500 笔记实测 top-3 相关度 9.0/10，该组第一）
  - 移动端快速捕获
- **短板**：**不给你手动结构**（想整理会觉得混乱）；中文识别明显下降；导出不便、数据锁在 Mem

#### Reflect
**定位**：每日笔记 + 双向链接 + 知识图谱，端到端加密。

- **核心功能模块**
  - 每日笔记（Daily Notes）为锚
  - 双向链接 / 反链、知识图谱可视化
  - AI 总结 / 扩写 / 列要点、自然语言搜索
  - 语音记录（含说话人标注）自动转写并建链
- **特色模块**
  - **间隔回顾**：内容一周后 / 一月后 / 三月后自动推给你
  - **最强加密**（E2E 可选）；捕获摩擦全组最低
- **短板**：AI 能力克制；无团队协作；无免费档（仅试用）

#### Tana
**定位**：给重度结构化用户的超级标签笔记。

- **核心功能模块**
  - **Supertag**：每个信息块可打多个标签，标签带属性
  - 数据库式查询（按标签组合精准检索）
  - **Tana AI**：自然语言命令执行查询 / 摘要 / 提取待办
  - 每周回顾从日记自动生成
- **特色模块**
  - **可编程笔记系统**：标签即 schema，属性即字段
  - **AI 命令可自定义**（如"从会议记录提取待办"）
  - 结构化上限全组最高
- **短板**：学习曲线最陡（前三天都在调 Supertag）；无原生移动端；简单场景属于过度设计

#### Capacities / Heptabase
| 产品 | 核心功能模块 | 特色模块 |
|---|---|---|
| **Capacities** | 对象化笔记（按"类型"而非文件夹组织）、AI 摘要 | 视觉型思考者友好 |
| **Heptabase** | 白板 + 卡片 + 研究 | 空间化思考，研究者/学生 |

## 二、开源项目

### 1. 个人 PKM 类

#### Logseq（~43k★ / AGPL-3.0）
- **核心模块**：大纲 / 块级引用、双向链接、知识图谱、PDF 标注、任务管理、插件
- **特色模块**：**块级引用 + 大纲思维**；本地优先 Markdown/Org 纯文本
- **短板**：核心维护放缓；UI 略逊 Obsidian

#### SiYuan 思源笔记（~45k★ / AGPL-3.0）
- **核心模块**：块编辑器、本地存储、官方同步、Docker 自托管、闪卡、PDF 标注、AI（走 OpenAI 兼容 API）
- **特色模块**：**块级 SQLite 索引 + SQL 式跨笔记关系查询**（全组唯一能对笔记跑关系查询）；中文友好；本地 AI 代理
- **短板**：社区比 Obsidian 小；`.sy` 专有格式（AI 工具需转换）；学习曲线陡

#### Trilium（~32–37k★ / AGPL-3.0）
- **核心模块**：层级笔记树、笔记克隆（一条笔记多处出现）、属性/关系、版本、脚本扩展、REST API、画布 / Mermaid / 思维导图 / 日历
- **特色模块**：**每笔记级加密 + 脚本自动化**；层级深度最强
- **短板**：界面老旧；非技术用户学习曲线陡

#### AFFiNE（~70k★）
- **核心模块**：块级文档、无界白板、数据库三合一；CRDT 实时协作；自托管（PostgreSQL + pgvector + Redis）
- **特色模块**：**文档 + 白板 + 数据库一体，且内置可指 Claude/OpenAI/Gemini 的 AI Copilot**
- **短板**：自托管吃资源；AI 自托管需 pgvector 增加架构复杂度；生态尚早

#### AppFlowy（~73k★ / AGPL-3.0）
- **核心模块**：Notion 式块编辑器、数据库视图、看板、日历、自托管服务端、离线优先
- **特色模块**：**开源 Notion 替代里界面最熟悉的一个**；Flutter + Rust 跨平台
- **短板**：AI 功能仍在补；企业治理弱

#### Joplin / Anytype
| 项目 | 核心功能模块 | 特色模块 |
|---|---|---|
| **Joplin**（~55k★） | Markdown 笔记、端到端加密同步、插件 | **E2E 加密同步最成熟** |
| **Anytype** | 本地加密对象库、类型化对象 | 本地优先 + 加密 + 个人免费 |

### 2. AI 知识库 / 本地 RAG 类

#### Khoj（~36–37k★ / AGPL-3.0）｜最像"个人知识助手"的开源项目
- **核心功能模块**
  - 索引源：Markdown / PDF / Org / Notion / GitHub / Word / 图片
  - Chat（本地或云 LLM 皆可）、语义搜索
  - 自定义 Agent、定时自动化（个性化 newsletter、智能通知）
  - 多平台：Web / Desktop / Android / iOS / **Obsidian 插件** / Emacs
- **特色模块**
  - **`/research` 深度研究模式**（多步自动追问）
  - **与 Obsidian 双向同步**（这是它跟你最直接重叠的地方）
  - 定时自动化：让助手在后台替你干活
- **短板**：自托管有门槛；AGPL-3.0 对闭源商用有传染约束

#### AnythingLLM（~63–65k★ / **MIT**）｜上手最快的全栈本地方案
- **核心功能模块**
  - **Workspace 隔离**：不同项目文档互不污染，可配 RBAC
  - 文档采集器 + 内置 LanceDB（另支持 Qdrant/Chroma/PGVector/Weaviate/Milvus/Pinecone）
  - RAG + 引用展示
  - 30+ LLM 提供商；Desktop（Win/Mac/Linux）+ Docker
  - 多用户 + 租户隔离（Docker）
- **特色模块**
  - **无代码 Agent Flow 构建器 + MCP 兼容**
  - **内置 Agent**：网页浏览、SQL 查询、文件操作
  - **Meeting Assistant**：设备端转写 + 摘要（不进会、不上云）
  - **Magic Features**：鼠标处听写 / 回声 / 自动补全
  - Background Jobs 定时任务；可在本地网络做设备间同步
- **短板**：有用户反映"答错还像对的"；**空载吃 ~2GB 内存**；UI 比较主观

#### RAGFlow（~88k★ / Apache-2.0）｜文档解析之王
- **核心功能模块**：模板化切片、混合检索 + 重排、页级引用、Agent + MCP、Docker Compose 部署
- **特色模块**
  - **DeepDoc 深度文档理解**：OCR + 表格结构识别（TSR）+ 版面分析（DLR）三视觉模型，表格/多栏/图表保留结构
  - 0.23+ **父子分块** + 图/表上下文窗口
  - 0.25 加 **Agent 沙盒**、用户级记忆隔离、发布灰度
- **短板**：部署重（PostgreSQL/Redis/向量库多组件）

#### Open WebUI（~147k★ / BSD-3 含品牌条款）
- **核心功能模块**：自托管多模型聊天界面、内置文档 RAG、工具/函数、SSO/RBAC/审计、离线部署
- **特色模块**：**Ollama 生态的事实核心**，最大社区；装完即给本地模型配一整套 UI
- **短板**：不是专门的知识库产品，知识管理是附带能力

#### Dify（~146–154k★ / 改版 Apache-2.0）
- **核心功能模块**：可视化工作流编排、Agent、RAG 流水线、可观测性、团队协作、API
- **特色模块**：**从原型到生产不重构**；Marketplace 插件市场；SOC2 / ISO 27001 企业版
- **短板**：多租户 SaaS 商用需商业授权

### 3. Obsidian 插件生态（**最该盯的一组**）

#### Smart Connections（~5.4k★ / **78.6 万下载，生态第一**）
- **核心模块**：本地 embedding 为每篇笔记建向量；侧栏实时推荐"相关笔记"；**Smart Chat**（对 vault RAG 问答）；Graph / List 视图显示语义相似度
- **特色模块**
  - **默认本地 embedding，无需 API key、不联网、不扣费**
  - **自动发现你手动没链接过的关联**（补全双链）
- **短板**：不做严谨问答；大库会拖慢速度

#### Copilot for Obsidian（~7.7k★ / 45 万下载）
- **核心模块**：侧栏聊天（可引用当前笔记/选中文本）、vault RAG、**引用溯源**、PDF 解析、20+ 预设 prompt（总结/翻译/润色/头脑风暴）、多提供商（OpenAI/Anthropic/Google/Ollama）
- **特色模块**
  - **RAG 与引用精准度是插件里最强的**（多源测评一致）
  - **V4 把 opencode / Claude Code / Codex 带进 Obsidian**（研究、写作、知识工作）
  - 可配成右键菜单做即时查询
- **短板**：笨重、占内存、后台常驻高、界面老旧、改写生硬

#### Claudian（~15.1k★ / 12 万下载 / 2025-12 创建）
- **核心模块**：把 Claude Code / Codex 嵌进 vault；选中笔记直接分析/改写/扩写；跨笔记执行任务（整理、重构、建链接）
- **特色模块**
  - **唯一能批量新建 / 删除 / 移动 / 整理文件的插件**（真正"动手"的 agent）
  - 增长最快（9 个月 15k★）
- **短板**：**不支持离线**；权限完全开放，新手慎用

#### Text Generator（~2.0k★）/ obsidian-mcp-plugin（~457★）
| 插件 | 核心功能模块 | 特色模块 |
|---|---|---|
| **Text Generator** | 模板 + 变量批量生成、多提供商 | 老牌模板化生成，写作工作流 |
| **obsidian-mcp-plugin** | 把 vault 变成 MCP Server | **任何 MCP 客户端（Claude Desktop / Cursor）都能读你的笔记** |
