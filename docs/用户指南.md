# Obsidian RAG 个人知识工作台：用户指南

## 1. 安装与启动

运行 `ObsidianRAG-Setup-0.2.1-win-x64.exe`，按向导安装。应用按当前 Windows 用户安装，不要求管理员权限，也不要求另装 Python、Node.js 或 Docker。桌面和开始菜单会出现“Obsidian RAG”。

应用启动后会打开本机浏览器页面。资料和数据库保存在 `%LOCALAPPDATA%\ObsidianRAG`，升级不会覆盖；卸载默认也会保留，便于以后重装恢复。

## 2. 首次设置

填写工作台名称并选择生成后端：

- **本机 Ollama**：先安装并启动 Ollama，在设置中填写已经下载的模型名，例如 `qwen2.5:7b`；
- **DeepSeek**：输入 API Key。密钥保存到 Windows 凭据管理器，不写入数据库或配置文件。

检索模型 `multilingual-e5-small` 在设置页明确下载，固定版本并使用 CPU。首次下载需要网络；失败后可重试。没有生成模型时，资料导入与关键词搜索仍可使用。

## 3. 添加和更新资料

- “连接资料文件夹”只读扫描原目录里的 Markdown、PDF 与 Jupyter Notebook，不修改原文件；文件变化后点击刷新。目录里混进扫描件或坏文件时，只有那一个会失败，其余照常导入。
- “上传文件”支持单独的 UTF-8 Markdown、文字型 PDF 和 Jupyter Notebook（`.ipynb`）；上传内容复制到产品数据目录。
- 来源面板里 PDF 按页连续滚动，命中页会自动定位并高亮命中的文字；Markdown 保留章节和行号；Notebook 保留单元格编号与行号。
- Notebook 只收录单元格的源码和纯文本输出；图片、图表等富媒体输出不参与检索，处理结果里会注明丢弃了多少处。
- 扫描件、加密 PDF、坏文件或超限文件会显示明确失败原因。首版没有 OCR。

移除资料只影响后续检索，不删除连接目录中的原文件；旧来源快照会继续用于历史会话和收藏核对。

批量移除：资料库、收藏、产出三个列表都有“批量选择”入口，可逐条勾选或全选后一次删除。第一下“删除”只展开确认框，写明将删除几项与各自的后果；“再想想”退回；第二下才真正删除。资料库的确认按勾选内容区分：来自已连接文件夹的资料只是暂时移除，刷新那个文件夹时会被重新导入；上传的资料不会回来。删除完成后，没能删除的项（例如仍在生成中的产出）会同原因一起单独列出；删除产出时，随它导出的图片会一并删除。

### 随包示例

安装包自带一份合成示例 `欢迎使用.md`，供你在还没有整理自己的笔记时先跑通流程。它不包含任何个人资料，也不需要联网。

导入方式：资料库页在还没有任何资料时，直接点击“导入随包示例「欢迎使用.md」”。导入后它和其他资料一样参与搜索和问答，可以随时移除。再次点击导入是幂等的，不会产生重复文件。

示例正文里演示了一段技术资料，导入后搜索 `PagedAttention` 应能命中并打开原文，这是安装后最快的自检方式。

随包文档（用户指南、发布说明、第三方许可）在设置页“随包文档”卡片里可以打开，它们只随安装包分发，不会被检索。

## 4. 搜索、提问与追问

资料库搜索适合先确认原文位置。知识问答会在每一轮重新检索，并用 `[S1]` 形式标注来源。点击标签或来源按钮可以打开回答当时的原文快照。

可以继续问“它解决什么问题”一类简单追问。历史对话只帮助理解指代，不作为事实证据；对象不明确时工作台会要求补充。点击“停止”会保留未完成文本，之后可以重试。停止远端连接不保证服务商已经取消计算或计费。

提问涉及天气、股价、航班等实时外部数据时，工作台会直接说明“资料里没有”而不调用模型。这个判断只是关键词启发式，宁可拦错也不放过；如果确认问题其实是针对你的资料，点回答下方的“仍然按资料提问”即可跳过判断重新检索。

## 5. 收藏、反馈和导出

带来源的完整回答可以收藏。收藏页允许修改标题和备注、回看来源，并导出 UTF-8 Markdown。未完成、失败或没有来源的回答不会成为收藏。

回答下方提供“有帮助、有遗漏、引用不对、回答不对”四个选项，先点“＋ 备注”可以再补一段文字说明哪里缺、哪条引用指错了位置。反馈连同备注默认只保存在本机，不会自动上传或用于训练。

## 6. 备份、恢复与诊断

设置页可以下载完整数据备份。备份包含资料快照、会话、收藏和导出，不包含模型缓存、日志或 API Key。恢复会先自动保存当前数据，完整校验备份后替换，随后必须退出并重新打开。

数据库升级失败时，应用进入安全恢复模式，不加载问答功能；选择升级前自动备份恢复后重启即可。下载的脱敏诊断只包含版本、状态和数量，不包含密钥、问题、回答、文件名、正文或本机绝对路径。

## 7. 常见问题

- **网页打不开**：再次从开始菜单启动；启动器会识别已有实例并打开正确端口。
- **Ollama 不可用**：确认 Ollama 正在运行，且设置中的模型已通过 `ollama pull <模型名>` 下载。
- **DeepSeek 失败**：检查网络、余额和 API Key；产品不会自动切换到另一个后端。
- **检索不到**：确认文档状态为“可搜索”，目录更新后执行刷新，尝试使用资料中的关键术语。资料库页没有资料时，可以先导入随包示例验证流程是否正常。
- **提问被直接拒绝**：问题里含“今天、最新、价格”等实时数据词时会走这个分支。若问题其实是针对你的资料，点“仍然按资料提问”跳过判断。
- **卸载后资料仍在**：这是默认的数据保护行为。确认不再需要且已有备份后，才手动处理 `%LOCALAPPDATA%\ObsidianRAG`。

## 8. 首版明确不包含

账号和云同步、联网研究、OCR、自动修改笔记、自动更新、后台遥测、自主执行任务的 Agent，以及自行训练模型。
