# Obsidian RAG 个人知识工作台：用户指南

## 1. 安装与启动

运行 `ObsidianRAG-Setup-0.2.0-win-x64.exe`，按向导安装。应用按当前 Windows 用户安装，不要求管理员权限，也不要求另装 Python、Node.js 或 Docker。桌面和开始菜单会出现“Obsidian RAG”。

应用启动后会打开本机浏览器页面。资料和数据库保存在 `%LOCALAPPDATA%\ObsidianRAG`，升级不会覆盖；卸载默认也会保留，便于以后重装恢复。

## 2. 首次设置

填写工作台名称并选择生成后端：

- **本机 Ollama**：先安装并启动 Ollama，在设置中填写已经下载的模型名，例如 `qwen2.5:7b`；
- **DeepSeek**：输入 API Key。密钥保存到 Windows 凭据管理器，不写入数据库或配置文件。

检索模型 `multilingual-e5-small` 在设置页明确下载，固定版本并使用 CPU。首次下载需要网络；失败后可重试。没有生成模型时，资料导入与关键词搜索仍可使用。

## 3. 添加和更新资料

- “连接 Markdown 文件夹”只读扫描原目录，不修改原文件；文件变化后点击刷新。
- “上传文件”支持单独的 UTF-8 Markdown 和文字型 PDF；上传内容复制到产品数据目录。
- PDF 引用保留页码；Markdown 引用保留章节和行号。
- 扫描件、加密 PDF、坏文件或超限文件会显示明确失败原因。首版没有 OCR。

移除资料只影响后续检索，不删除连接目录中的原文件；旧来源快照会继续用于历史会话和收藏核对。

## 4. 搜索、提问与追问

资料库搜索适合先确认原文位置。知识问答会在每一轮重新检索，并用 `[S1]` 形式标注来源。点击标签或来源按钮可以打开回答当时的原文快照。

可以继续问“它解决什么问题”一类简单追问。历史对话只帮助理解指代，不作为事实证据；对象不明确时工作台会要求补充。点击“停止”会保留未完成文本，之后可以重试。停止远端连接不保证服务商已经取消计算或计费。

## 5. 收藏、反馈和导出

带来源的完整回答可以收藏。收藏页允许修改标题和备注、回看来源，并导出 UTF-8 Markdown。未完成、失败或没有来源的回答不会成为收藏。

“有帮助、遗漏、引用不对、回答不对”反馈默认只保存在本机，不会自动上传或用于训练。

## 6. 备份、恢复与诊断

设置页可以下载完整数据备份。备份包含资料快照、会话、收藏和导出，不包含模型缓存、日志或 API Key。恢复会先自动保存当前数据，完整校验备份后替换，随后必须退出并重新打开。

数据库升级失败时，应用进入安全恢复模式，不加载问答功能；选择升级前自动备份恢复后重启即可。下载的脱敏诊断只包含版本、状态和数量，不包含密钥、问题、回答、文件名、正文或本机绝对路径。

## 7. 常见问题

- **网页打不开**：再次从开始菜单启动；启动器会识别已有实例并打开正确端口。
- **Ollama 不可用**：确认 Ollama 正在运行，且设置中的模型已通过 `ollama pull <模型名>` 下载。
- **DeepSeek 失败**：检查网络、余额和 API Key；产品不会自动切换到另一个后端。
- **检索不到**：确认文档状态为“可搜索”，目录更新后执行刷新，尝试使用资料中的关键术语。
- **卸载后资料仍在**：这是默认的数据保护行为。确认不再需要且已有备份后，才手动处理 `%LOCALAPPDATA%\ObsidianRAG`。

## 8. 首版明确不包含

账号和云同步、联网研究、OCR、自动修改笔记、自动更新、后台遥测、自主执行任务的 Agent，以及自行训练模型。
