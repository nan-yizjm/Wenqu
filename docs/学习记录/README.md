- [37：信息图与无头渲染](37-信息图与无头渲染.md)：把一份产出画成一张 PNG。两个关键取舍——信息图是**导出器而不是第三种产出类型**（不动 `kind` 的 CHECK 约束、不重建表、无迁移），以及**版面高度是算出来的**（所有文本行不换行，所以截图不裁不拖白边）。真机 Edge 909 ms 出 2160×2108；浏览器不可用时降级为"导出 HTML 给你自己打开"而不算故障。含一个**只有把导出的 PNG 打开看才会发现**的缺陷：副标题被自己的省略号吃掉，而 `assertIn` 照样通过。
- [38：退出入口与诚实响应](38-退出入口与诚实响应.md)：补上"正常使用下没有退出入口"（常驻进程不会自己结束，而**关掉浏览器标签不算退出**——这句话直接写在按钮旁边）。两处诚实：没有接启动器时接口回 503 而不是假装"正在退出"（与联网那块"未配置就说未配置"同一条线），以及"退出不删数据"由接口自己在响应里签字。含**一条决定不做**：心跳 + 闲置自动退出，四条理由（后台标签定时器被节流、长任务会被误杀、自动化脚本一个心跳都不发、关标签本就不损坏）。真实退出验到浏览器外面——端口不再应答 + 启动器日志里的 `server_stopped`。
- [39：联网状态入库](39-联网状态入库.md)：DB v10（`messages.web_state_json`）。联网状态原本只活在一帧流式事件里，答完重取一次会话就没了——于是"这次没联上"变成"看起来就像今天没什么可网的"。核心判断是**`NULL` 不等于 `off`**：旧行和"被守卫拦下、根本没走到联网那层"的回答都留 `NULL`，不替历史编结论。顺带删掉前端那张与消息重复的组件状态表。含一次真实数据根的存量升级、真模型端到端，以及"把提示改挂错位置 → 界面验证挂 4 项"的反向对照。
- [40：批量删除](40-批量删除.md)：资料 / 收藏 / 产出三个列表的选择式批量删除。语义各不相同就各守各的：资料**一次事务一次快照**（逐条删会重建 30 次检索快照）、文件夹来源的"移除"是**暂时的**（确认框按选中内容如实写出）、正在生成的产出**跳过而非报错**（API 层 busy 是 200+skipped 不是 500）。共用一个请求体（空选择 422、去重、限长）、一个确认条组件、两段式页面内确认。含一次验收排查：结果条"消失"其实是**源码改了、构建产物没重建**——与"组件测试全绿但交付物不可用"同类的另一面。
- [41：上下文窗口与证据预算](41-上下文窗口与证据预算.md)：修掉 P3 遗留的"超窗无防护"——Ollama 对超出 `num_ctx` 的输入**静默截断**，叠加产品两层字符硬切一共三层不说话。修法是三个决定：窗口是产品的**签约值**（`num_ctx=8192`，不再靠模型默认 4096 碰运气）、证据按**字节预算整条裁**（字符口径对中文会高估可装条数；硬切会让界面出现模型只见过半句的引用）、裁了必须说（`evidence_note` 落库，口径与 39 的 `web_state_json` 同构）。真模型端到端分两段：真实语料**不误裁**、空库长文**必裁**。含双实例并发抢 Ollama 撞 120 秒超时的既有事实记录。
- [42：断开归类](42-断开归类.md)：补上"删光资料后归类卡片删不掉"的出口——`DELETE /api/v1/libraries/{id}` = 停用来源 + 其下资料一并软删（一次事务一次快照）+ **原文件不动**。核心是竞态防护：刷新扫描进行中断开时，扫描会把个别文档"复活"，快照查询加 `libraries.active=1` 才是最后一道闸。含短路验证抓到的**空壳测试现行**（复活测试没走防护挡的那条路，去掉防护照样过），以及 npm.cmd 在 Git Bash 会话里解析错 node、从 registry 下载 node@26 来跑 vitest 的环境事故（改走 `./node_modules/.bin/`）。

## 上一轮已交付的基础功能

- E5 文档向量保存为本地 NPZ，自动校验指纹并重建失效缓存。
- BM25、向量、RRF 混合检索共用入口，能够查看通道名次和评分贡献。
- RAG 可切换检索器；连续问答复用进程内索引，不拼接历史对话。
- 生成报告保存实际上下文和检索轨迹；提供离线阅读命令。
- 同一题集的三路对比、带时间戳的报告、源码和数据指纹。

本轮没有提交、推送、打标签，没有修改原始 Obsidian 笔记，也没有修改评测题和答案要求。缓存和含笔记原文的报告继续位于被 Git 忽略的 `data/generated/`。学习记录中只记录必要的实验摘要。

## 先运行一次

在 PowerShell 中：

```powershell
Set-Location -LiteralPath '<项目目录>'
.\.venv\Scripts\python.exe -X utf8 -m src.chat --provider ollama --retriever hybrid --chunks-file data/generated/token_v1/chunks.json --rerank --context-policy blocks
```

输入完整问题，例如“一个基础 RAG 系统从用户问题到最终回答通常经历哪些步骤？”。用 `:method vector`、`:method bm25` 切换候选检索方式，用 `:quit` 退出。首次问题需加载编码和重排模型；后续问题复用模型和索引。省略新增三个选项则使用旧语料、不开重排、沿用 Legacy 上下文。

这不是已经实现对话记忆的 Chatbot：“它还有什么问题？”缺少独立语义，当前请写出具体对象。
