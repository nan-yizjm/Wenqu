# 目录结构与占用（2026-09-17）

本目录共约 **6.2 GB**。其中约 **6.2 GB 是可重建的环境与构建产物**，真正属于"项目内容"的只有约 **3.2 MB**（Git 跟踪 231 个文件）。这份清单的目的是让"哪些能删、哪些删了要重来"一眼可查。

数据来源：`du -sh` 递归实测（2026-09-17 09:35），文件计数用 `ls` / `find` / `git ls-files` 直接数，没有估算。

> **09-17 更新**：使用者当天手动删除了两份被取代的便携版，回收 1.28 G，`dist/` 从 1.9 G 降到 **642 M**。下表 `dist` 一行已改为实测值；**总量 6.2 G 是"删除前实测 7.5 G − 回收 1.28 G"推算的**——两个 venv 与 `data`/`build`/`web` 等自上午实测以来未变，只有 `dist` 变小，故未重跑那 10 分钟的递归统计。这点差别如实标出，避免把推算值当成实测值引用。

## 5. 复现这份清单

```bash
du -sh */ .[!.]*/ | sort -hr              # 顶层目录占用（递归，约 10 分钟）
du -sh dist/*/ data/generated web/node_modules web/dist web/src   # 大头细分
git ls-files | wc -l                     # 真正被跟踪的文件数
```
