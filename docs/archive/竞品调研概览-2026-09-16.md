## 做了什么

联网检索（中英文源，9 轮）主流的个人知识助手商业产品与 GitHub 热门开源项目，按类别梳理核心功能模块、优势、局限与适用场景，并落到 obsidian-rag 的差异化定位。

## 核心结论（三条）

1. **不是一条赛道，是四条**：笔记软件自带 AI / 通用 AI 挂知识库 / 专门第二大脑 / 开源自建 RAG。混着比只能得出"各有千秋"。
2. **直接对手不是 NotebookLM，是 Obsidian 插件**：Copilot（~7.7k★）、Smart Connections（~5.4k★）、Khoj（~36.9k★ 插件端）——同一 vault、免费、零安装摩擦。
3. **最稀缺的资产是"能证明自己检索质量"**：30+ 产品/项目在公开范围内无一公开检索评测集，而你有。

## 关键判断

- 守住：Obsidian 原生深度（含 .ipynb）+ 可验证检索质量 + 离线/凭据托管。
- 放弃：多模态产出、Agent 自动整理、团队协作、跨平台同步（均被更强的玩家占位）。
- 最大风险：独立桌面 App 增加安装摩擦，却可能只做到免费插件能做的事。

## 自省（已推翻的判断）

- "公开评测集是独有优势" → 修正为"公开可查范围内，个人/小团队产品里唯一"。
- "本地优先是趋势所以能赢" → 本地优先是主流卖点，但**收费的本地优先在 Obsidian 生态里尚无验证过的成功案例**，这是最大不确定性。

## 待用户拍板

1. 差异化主线是否认"Obsidian 原生深度 + 可验证质量"而非功能广度。
2. 是否先做小样本付费意愿验证，再决定投入。
3. 评测集是否对外公开。

## 待补

- GitHub 星数逐个复核（API 当日限流）。
- "公开范围内唯一评测集"需更系统的检索才能下定论。
- 国内产品（ima/飞书/语雀）实际检索质量无公开评测。
