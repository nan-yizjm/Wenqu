# 文档索引

`docs/` 顶层除本索引外有 20 篇文档，另有 `学习记录/` 47 篇。这个索引解决一个具体问题：**其中有几篇是互相取代的关系，光看文件名看不出哪篇当前生效**，外人（评审、朋友、未来的自己）容易照着已作废的排序去执行。

状态图例：**生效** = 当前决策以此为准 ｜ **已被取代** = 保留作历史，别按它执行 ｜ **参考** = 素材，不构成决策 ｜ **随包** = 会被打进安装包，改前确认

「跟踪」列表示是否已进入 Git。带 ✗ 的是本地规划文档，按约定未提交，**克隆仓库看不到它们**。

## 改这份目录时的两条注意事项

1. **别随便挪 `docs/` 里的文件**。多篇文档按 `docs/xxx.md` 互相引用（`产品检索评测`、`改进记录`、`项目深读报告` 都这么引用过），挪动会静默破坏这些路径。要挪就顺手 `grep -rn "<旧路径>"` 一遍。
2. **新增文档时顺手更新本索引**，并标清它是"生效"还是"取代了谁"。否则半年后又会出现"看不出哪篇有效"的问题——这正是本索引存在的原因。
