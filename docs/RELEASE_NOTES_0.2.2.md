# Obsidian RAG 0.2.2

在 0.2.1 的安装与检索基础上，把知识工作补成完整的闭环：资料可以批量管理、文件夹来源可以断开、产出可以生成并导出、应用有了正常使用下的退出入口；同时修掉一个从第一版就存在的沉默缺陷——回答引用的证据可能被模型静默丢弃。

> **如果你试用过 0.2.1，请重新安装这一版。** 0.2.1 安装包构建于 09-16，其后 50 个提交没有进包；其中包括下面列出的全部功能（0.2.1 的便携版带了其中一部分界面修复，安装版没有）。

## 相对 0.2.1 新增

- **产出（Studio）**：对选定的资料主题生成学习指南（由本机模型撰写）与思维导图（零模型、可复现）。每份产出带一个**诚实的回链命中率**——引用覆盖率而不是事实正确性，实测数字与不足都写在界面里（详见学习记录 36）；
- **信息图导出**：把一份产出画成一张 PNG（或导出 HTML），版面高度按内容算出、不裁切不拖白边；本机没有可用浏览器时降级为 HTML 导出，不算故障；
- **批量删除**：资料库、收藏、产出三个列表都支持批量选择；第一下只展开确认框、写明各自后果，第二下才真正删除；正在生成的产出会被跳过并如实列出，不会报错也不会假装成功；
- **断开归类**：资料页顶部每个已连接的文件夹卡片可以断开——来源停用、其下资料一并移除，**原文件夹与文件不会被删除**，重新连接即可再次导入；
- **退出入口**：侧栏底部常驻"退出工作台"，两段式确认；退出不删任何数据，会在收尾页说明资料的去向。没有接系统启动器时接口明确回"无法退出"，不假装正在退出；
- **记忆与联网的接缝**：每条引用标注"来自哪一层"（笔记／记忆／网络）；联网搜索默认关闭，关闭时在 socket 层强制不出网，开启时只发出查询词，失败如实标注"这次没有联上"；
- **证据不再被静默丢弃**：本机模型（Ollama）的上下文窗口由产品签约为 8192；放不下的证据按 UTF-8 字节预算整条裁剪并**在回答旁注明**，不再出现"引用了模型其实没见过的内容"；
- 三项界面修复：窗口自适应窄屏、会话可以删除、应用内文件夹选择器真正可达。

## 相对 0.2.1 修复

- 回答引用的证据超出模型窗口时被**静默截断**：旧版把整段证据塞给模型，超出部分被无声丢弃，界面却照常显示引用。现在按预算裁剪并注明；
- 产出生成失败后历史产出打不开、删除按钮点不到的界面状态缺陷；
- 验收脚本自身的多处缺陷（`application/json` 解码、测试重复继承等）。

## 已知限制

- **回链命中率的实测值为 38.2%**（4 个主题中 2 个为 0%）：这是"引用覆盖率"的诚实数字，不是质量承诺；提升方案尚未实施；
- 产出目前只导出 PNG 与 HTML，**PPTX 未做**；信息图是图片，其中的文字不可选中、不可检索；
- 本机模型一次生成的耗时可能达到分钟级；两个实例同时跑会争用同一个 Ollama 并可能超时；
- 扫描版 PDF 没有 OCR；追问只覆盖常见代词与省略问法；
- 无账号、云同步、自动更新或遥测；联网搜索默认关闭且可验证地不出网。
