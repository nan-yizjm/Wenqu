# Wenqu 0.2.3

2026-10-08。Windows x64 本地知识工作台，原名 Obsidian RAG。本版完成更名、安全修复、浏览器回退与项目收尾。

## 修复

- Ollama 地址按 URL 主机名、协议与端口校验，拒绝伪装成本机的域名、用户信息段和非法 URL；带 Origin 的 API 请求必须同源。
- 备份恢复拒绝 Windows 路径穿越、盘符、保留设备名、符号链接、大小写重名和损坏清单；写入前再次检查路径边界，损坏数据库返回 422。
- 自动探测的信息图渲染先尝试 Edge，失败后尝试其他已安装浏览器。显式指定浏览器不会静默换用其他浏览器。失败保留 HTML，并记录真实原因。
- 更新 pypdf、python-multipart、setuptools 与 source-map-js 安全补丁。
- 构建脚本检查各外部命令退出码；安装升级只清理本次安装目录中的旧品牌入口，避免递归删除固定目录。

## 交付与兼容

- 产品、EXE 与安装包统一使用 Wenqu；版本号 0.2.3。
- 安装 AppId、`%LOCALAPPDATA%\ObsidianRAG` 数据目录及主题存储键保持兼容。
- 产品默认 BM25，可选 E5 混合检索；Ollama 与 DeepSeek 生成路径保留。
- 增加 Windows CPU CI、真实界面展示、SVG 架构图与开发/复现说明。

## 验收说明

当前版本的实际测试、安装、界面与依赖审计结果见 [收尾报告](https://github.com/nan-yizjm/obsidian-rag/blob/main/docs/收尾报告-2026-10-08.md)。测试通过表示覆盖到的行为符合预期，不表示模型回答已自动证明正确。

历史安装包在单独的归档 Release 中用于恢复，包含已知旧问题，不作为最新版本推荐。下载 0.2.3 后请对照随包 `.sha256` 校验。

## 现有限制

PDF 仅支持文字提取，不含 OCR；联网与记忆仍为默认关闭的接口接缝；DeepSeek 会接收问题、必要历史与检索片段。没有云同步、自动更新或多用户能力。
