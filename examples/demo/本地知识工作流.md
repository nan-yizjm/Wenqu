# 示例资料：本地知识工作流

## 接入资料

连接 Markdown 文件夹时只读扫描，不修改原笔记。上传的 Markdown、文字型 PDF 和 Notebook 复制到产品数据目录，形成可追溯的文档版本。

## 提问与核对

先检索证据，再在上下文预算内交给生成模型。回答通过 [S1] 等标签打开来源，Markdown 可以查看章节和行号，PDF 可以查看页码。追问会重新检索，历史回答不会自动变成事实证据。

## 保存成果

将有用的回答加入收藏，补充标题和备注，再导出 UTF-8 Markdown。Studio 可以生成学习指南、思维导图和信息图；导出的 Markdown 可以放回 Obsidian。

## 数据保护

安装目录与个人数据分离。升级前验证资料、会话和收藏仍然可用；备份恢复后重新启动工作台。DeepSeek 密钥存入 Windows 凭据管理器，不写入产品数据库。
