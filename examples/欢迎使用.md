# 欢迎使用个人知识工作台

## 你可以怎样使用它

把 Markdown 文件夹或文字型 PDF 接入工作台后，可以先搜索原文，再向本机 Ollama 或 DeepSeek 提问。回答中的 `[S1]`、`[S2]` 可以打开当时使用的来源快照。

## 一次完整工作流

1. 在“资料库”上传这份示例文件。
2. 搜索“完整工作流”。
3. 在“知识问答”询问：“个人知识工作台的一次完整工作流是什么？”
4. 点击回答引用，核对本节原文。
5. 收藏回答，写一条备注，再导出 Markdown。

## 示例：一段技术资料长什么样

下面这段是合成示例，用来演示“搜到原文再提问”是什么体验。

PagedAttention 要解决的是 KV Cache 的显存碎片问题。传统实现为每条序列预分配一块连续显存，序列长度参差不齐时就会留下大量无法复用的空隙；PagedAttention 把 KV Cache 切成固定大小的块，像操作系统的虚拟内存分页那样按需映射，于是显存利用率更高，同一个 batch 里也能容纳更多并发请求。

需要核对时可以搜索“PagedAttention”，回到这一段原文。

## 产品边界

工作台只依据已接入的静态资料回答，不提供实时天气、价格或订票服务。扫描版 PDF 暂不支持 OCR。选择 DeepSeek 时，问题、必要的近期对话和本轮检索片段会发送给远端服务；选择 Ollama 时生成留在本机。
